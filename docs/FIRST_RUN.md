# Первый запуск на ПК с Windows 11 — промпт для чата Claude Desktop

Скопируйте текст ниже в новый чат Claude Code (Claude Desktop) на ПК
(папку можно не выбирать — чат сам склонирует репозиторий). Облачная сессия, в которой писался код, не
имела доступа к польским площадкам — поэтому первый запуск и проверка
источников делаются на месте.

---

Ты работаешь в репозитории wroclaw-analyzer
(https://github.com/MaxDorovskiy/wroclaw-analyzer, ветка `main`). Если папки
ещё нет — склонируй его в `C:\dev\wroclaw-analyzer` и открой там. Прочитай
`CLAUDE.md`, `docs/FIRST_RUN.md` и `deploy/windows/README.md`. Задача — поднять
систему на этом ПК и подтвердить, что адаптеры источников понимают живые
ответы площадок.

1. Проверь, что стоят Git, Python 3.11+, Node LTS; если нет — скажи, что
   поставить. Ollama уже есть — узнай список моделей (`ollama list`).
2. Создай `deploy\windows\env.ps1` из примера: пароль администратора и
   пароль для логина `yulia` (WRO_WEB_USERS) придумай и скажи мне,
   `WRO_DATA` — папка на большом диске (спроси, на каком).
3. Запусти `deploy\windows\install.ps1` (PowerShell от администратора).
4. Запусти `scripts\probe_sources.py` для продажи и для аренды. Если имена
   полей разъехались — чини `backend/app/sources/otodom.py` / `olx.py` по
   сырым ответам в `%WRO_DATA%\probe`, добавляй фикстуры в `tests/fixtures`
   из реальных (обезличенных) ответов и прогоняй `pytest tests -q`.
   Если Otodom отдаёт 403 с `x-datadome` — переключи `fetch_mode=browser`.
5. Запусти первый прогон продажи (`scrape_trigger.ps1 -Kind sale -MaxJitterMin 0`),
   следи за «Прогони». После окончания — аренду. Покажи мне сводку:
   сколько объявлений, сколько с осиедле, сколько незнакомых мест в
   «Прогони → незнакомые значения», сколько с телефоном.
6. Перевод — через Ollama (решение владельца). В «Налаштуваннях» поставь
   модель из `ollama list` (подойдёт qwen3.5 / gemma3 от 9b),
   переведи 20 объявлений кнопкой «Перекласти чергу» и покажи мне 3 примера
   перевода PL → UK, чтобы я оценил качество.
7. Сверь соответствие осиедле → дзельница в `backend/app/geo.py` с
   https://geoportal.wroclaw.pl/osiedla/ (помечены «?»).
8. Всё, что поправил, закоммить по-русски и запушь в `main`.
