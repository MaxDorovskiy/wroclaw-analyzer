## Что сделано

- Исследование площадок и рынка — `docs/RESEARCH.md` (площадки закрыты
  прокси среды разработки, структура по описаниям парсеров; проверка на месте
  — `scripts/probe_sources.py`).
- Архитектура, контракт API, ТЗ v1.0 → v1.1 (Windows 11, контакты, Юлия).
- Бэкенд целиком: модели, адаптеры otodom/olx, нормализация, география,
  прогон, дубли, выгодность, доходность, перевод (ollama/anthropic/google/deepl),
  курсы НБП, API, тесты на фикстурах.
- Фронтенд (React/Vite, украинский, PL|UK) — отдельным агентом по контракту.
- Установка на Windows (`deploy/windows/`), скрипты, демо-данные,
  документация, `docs/FIRST_RUN.md` — промпт для чата на ПК.

## Ответы на вопросы 2–3

Код живёт в GitHub, база — локальный SQLite-файл на той машине, где запущен
сервер; с Mac переносить нечего (данных ещё нет). Первый запуск и проверка
источников — новым чатом Claude Desktop на ПК (облачная сессия до площадок не
дотягивается). Если речь была и о переносе КИЕВСКОЙ системы на ПК — это
отдельная задача (658 МБ базы + 37 ГБ фото, launchd → Планировщик, TLS-шлюз).
