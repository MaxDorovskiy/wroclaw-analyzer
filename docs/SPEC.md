# ТЗ: Wrocław Analyzer — сбор и анализ объявлений о квартирах во Вроцлаве

**Версия 1.2 — 18.09.2026.** Мастер-документ требований. При новых вводных
версия поднимается (1.0 → 1.1), журнал версий внизу.

## 1. Цель

Дать Максиму и Руслане тот же инструмент, что RE Analyzer в Киеве, но для
Вроцлава: ежедневно собирать объявления о продаже и аренде квартир с
польских площадок, находить объявления дешевле рынка, считать доходность от
сдачи, показывать рынок по районам и его движение во времени — и всё это
**по-украински с сохранением польского оригинала**.

## 2. Пользователи и сценарии

- Владелец (Максим) — ищет квартиры для покупки/флиппинга/сдачи, смотрит с
  Mac и с ПК в той же сети, иногда с телефона снаружи.
- Руслана — просматривает каталог и избранное.
- Юлия — знакомый риелтор во Вроцлаве, работает по аренде: ей нужны карточки
  контактов арендодателей и продавцов (имя, тип, телефон, все объявления).
  У неё **свой логин** (роль «просмотр»: каталог, карточки, избранное, заметки,
  экспорт; без настроек и прогонов), а владелец видит в «Журналі», что она
  открывала, искала и отмечала.
- Сценарии: «что нового за сутки и дешевле рынка», «карточка объявления с
  переводом», «сколько стоит метр в Krzyki 3-комн. и куда движется»,
  «в каких осиедле аренда даёт больше 6%».

## 3. Рамки первой версии

Входит: квартиры (mieszkania), продажа и аренда, город Вроцлав; источники
**otodom.pl** и **olx.pl**; перевод PL→UK; дубли между источниками; история
цен; снятие с продажи; выгодность; доходность; статистика по осиедле и
дзельницам; индекс цен; избранное и заметки; экспорт CSV/XLSX; basic-auth;
расписание launchd; уведомления в Telegram о новых выгодных — **v1.1**.

Не входит (см. DEFERRED.md): Morizon/Gratka/NO, первичка с
rynekpierwotny, дома и участки, фотографии на диске, проверка ремонта
моделью, цены сделок (RCN), карта.

## 4. Функциональные требования

### 4.1 Сбор

- F1. Прогон продажи 2 раза в сутки, аренды 1 раз; окна не пересекаются с
  киевской системой (§11 ARCHITECTURE). Запуск — Планировщик Windows.
- F2. Темп ≤ 15 запросов/мин на источник, источники по очереди,
  возобновляемость с последней страницы, фолбэк на Chromium при DataDome.
- F3. Upsert по `(source, source_id)`; `first_seen`/`last_seen`; история цен
  при смене; снятие после 3 дней невидимости при полном обходе; строки не
  удаляются.
- F4. Хвост Otodom: описание, характеристики, координаты, картинки (ссылки).
- F5. Отметка жизни, сторож 3 часа, пауза со сроком, статусы прогона.
- F6. `probe_sources.py` — проверка адаптеров на новом месте до первого
  прогона.

### 4.2 Нормализация и дубли

- F7. Единые поля (§2 ARCHITECTURE), класс состояния (§5), осиедле/дзельница
  по справочнику, продавец (частник/агентство/застройщик).
- F8. Дубли: `external_url`, ключ по числам, первая картинка; представитель
  — самое дешёвое активное; кнопка «інша квартира».

### 4.3 Аналитика

- F9. Выгодность: медиана пула похожих с релаксацией уровней, измеренная
  поправка на площадь, флаг тонкой базы, объяснение шагов в карточке и
  скриптом.
- F10. Доходность: медиана ставки аренды по уровням, вложения с отделкой у
  голых/убитых, объяснение в карточке; топ осиедле по доходности.
- F11. Статистика: медиана/квартили zł/м², число активных, новых и снятых за
  30 дней, медиана дней в продаже — по осиедле и дзельницам, с фильтрами.
- F12. Индекс цен по одним и тем же объявлениям, месяц/квартал.
- F13. Курсы НБП: цены в USD/EUR рядом с PLN.
- F13a. Контакты: имя, тип (власник/агентство/забудовник), телефон (с карточки
  Otodom), id на площадке; раздел «Контакти» с фильтром «лише власники»,
  поиском, экспортом CSV/XLSX; в карточке — блок контакта и «усі оголошення
  продавця». Телефоны OLX — DEFERRED, пункт 2.

### 4.4 Перевод

- F14. Заголовок и описание — машинный перевод PL→UK выбранным провайдером
  (ollama по умолчанию; anthropic / google / deepl по ключу), кэш по хэшу,
  суточный потолок, перевод по требованию из карточки.
- F15. Структурные значения — словарём; незнакомые значения — в отчёт.
- F16. Оригинал всегда рядом с переводом; переключатель показа.
- F17. Интерфейс — на украинском.

### 4.5 Интерфейс

- F18. Каталог с фильтрами (комнаты, цена, м², zł/м², дзельница, осиедле,
  рынок, состояние, источник, продавец, год, этаж), сортировкой, постраничным
  выводом, хэш-адресом, экспортом.
- F19. Карточка: два столбца PL | UK, характеристики, история цен, дубли,
  объяснение скидки и доходности, избранное, заметка, правка осиедле и
  состояния, «перекласти зараз», ссылка на источник.
- F20. Вигідні (пресеты: скидка ≥ 10%, ≥ 15%, новые за сутки), Оренда,
  Статистика (таблица + графики), Прогони (история, пуск/стоп/пауза),
  Налаштування (провайдер перевода, ключи, пороги, расписание, пароль не
  показывать).
- F21. Страница обязана объяснять 404 ручки после выкатки без перезапуска.

## 5. Нефункциональные

- N1. Python 3.9-совместимый код, SQLite WAL, ORM без перебора текстовых
  колонок на больших выборках.
- N2. Basic-auth на всё, включая статику; логины и пароли в `env.ps1`, не в
  git; роли admin / viewer; журнал действий по пользователям (`access_log`).
- N3. Проверка правок на копии базы; тесты `pytest` на фикстурах.
- N4. Комментарии в коде — «почему», с цифрами; коммиты по-русски.
- N5. Логи с ротацией в триггере; время внутри UTC, наружу Киев.

## 6. Этапы

1. **Каркас и адаптеры** (эта сессия): база, прогон, otodom/olx, дубли,
   аналитика, перевод, API, фронтенд, скрипты, тесты, документация.
2. **Первый запуск на Mac**: `probe_sources.py`, правка имён полей, первый
   полный прогон, сверка осиедле по геопорталу, выбор провайдера перевода.
3. **Неделя накопления**: пороги пулов, поправка на площадь, словарь
   незнакомых значений, Telegram-уведомления (v1.1).
4. **Расширение** по DEFERRED: третий источник, первичка, цены сделок.
