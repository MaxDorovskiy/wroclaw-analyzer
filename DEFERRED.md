# Отложено сознательно, а не забыто

У каждого пункта — измеримый признак возврата и способ проверить, что стало
лучше. Заглядывать в начале сессии.

## 1. Третий источник (Morizon/Gratka или nieruchomosci-online)

**Отложено:** доля уникальных объявлений неизвестна; Morizon/Gratka в основном
зеркалят агентские фиды, которые стоят на Otodom.
**Признак возврата:** после месяца данных доля активных объявлений продажи,
у которых `group_size == 1` и `source == 'olx'` с `business = true` (агентские
без зеркала), меньше 15% — значит Otodom+OLX покрывают рынок и третий источник
не нужен; больше 30% — нужен. Считать:
`SELECT source, seller_type, group_size=1, COUNT(*) FROM listings WHERE is_active=1 GROUP BY 1,2,3`.
**Как:** новый модуль в `backend/app/sources/`, класс с `iter_pages`, строка в
`REGISTRY`, фикстура и тест.

## 2. Телефоны OLX

**Отложено:** API OLX отдаёт только флаг `contact.phone`, номер — после входа
и капчи. У агентских объявлений телефон есть на зеркале Otodom.
**Признак возврата:** в «Контактах» активных частников OLX без телефона
больше 300 (`seller_type='private' AND source='olx' AND seller_phone IS NULL`).
**Как:** Playwright с сохранённой сессией OLX (вход владельца), клик по
«Zadzwoń», темп ≤ 1 номер/мин, только по избранным и выгодным — как
`phone_browser.py` в Киеве.

## 3. Осиедле для OLX-объявлений

**Отложено:** OLX даёт дзельницу; осиедле можно вывести из улицы или
координат `map.lat/lon` (радиус до 1 км — точности хватает не всегда).
**Признак возврата:** больше 40% активных объявлений без `osiedle`
(`SELECT COUNT(*) FROM listings WHERE is_active=1 AND osiedle IS NULL`).
**Как:** справочник улица → осиедле (собирается из Otodom-объявлений, где есть
и улица, и осиедле: ≥ 3 совпадений — правило) плюс полигоны осиедле с
geoportal.wroclaw.pl для координат.

## 4. Пороги пулов и коэффициенты площади

**Отложено:** `MIN_POOL`, `TRUST_MIN_POOL`, границы полос — из Киева/здравого
смысла; поправка на площадь измеряется, но её надёжность не проверена.
**Признак возврата:** первый полный месяц данных; измерить долю объявлений с
`deal_thin_base = 1` (цель < 30%) и разброс `area_coef_sale` между
пересчётами (устойчив ли).

## 5. Первичка от застройщиков (rynekpierwotny.pl)

**Отложено:** нужна отдельная сущность «инвестиция» (аналог ЖК с ЛУН).
**Признак возврата:** владелец ставит задачу «купить у застройщика», или доля
`market='primary'` среди активных > 35%.

## 6. Цены сделок (RCN, sonarhome)

**Отложено:** платно; нужно для калибровки «оферта → сделка» (сейчас ~8%).
**Признак возврата:** первая реальная покупка владельца во Вроцлаве — сверить
свою цену со скидкой, которую показала система.

## 7. Фотографии на диске и проверка состояния моделью

**Отложено:** храним только ссылки на CDN; класс состояния — по словам.
В Киеве модель по фото стала полезной только после разметки владельцем.
**Признак возврата:** владелец разметил ≥ 200 карточек вручную
(`condition_override IS NOT NULL`) — тогда есть эталон для замера точности.

## 8. Telegram-уведомления о выгодных (v1.1)

**Отложено:** сначала убедиться, что скидка считается правдоподобно.
**Признак возврата:** владелец подтвердил хотя бы 10 «выгодных» как
действительно выгодные (избранное среди `discount_pct >= 10`).
**Как:** `notifier.py` по образцу киевского, ключи `telegram_token/chat_id`
уже в настройках.

## 9. Индекс цен: порог 20 объявлений на период

**Отложено:** до накопления истории индекс пуст (нужны объявления, жившие на
двух границах месяца).
**Признак возврата:** второй полный месяц — проверить, что `n` в
`/api/price_index` ≥ 200 и индекс не скачет больше ±3% в месяц.
